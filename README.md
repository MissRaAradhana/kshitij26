 Personal Portfolio Website 

A modern, responsive personal portfolio website built using HTML and CSS.  
The website showcases my projects, skills, and contact information through a clean, aesthetic interface with a focus on user experience and visual design.

 About The Website

This portfolio website includes:

- A hero section introducing my work and skills
- A projects section displaying featured projects
- A skills section highlighting my abilities
- A contact form for visitors to reach out
- Smooth navigation between sections
- A responsive layout optimized for different screen sizes

 Design & Styling Features

 Modern UI Design
- Custom gradient backgrounds
- Glassmorphism-inspired cards
- Rounded corners and soft shadows
- Consistent purple-themed aesthetic

 Theme Toggle
- Interactive dark/light mode switch
- Dynamic color changes using CSS variables
- Theme colors designed to maintain visual consistency

Interactive Effects
- Hover glow effects on:
  - Navigation links
  - Project cards
  - Buttons
  - Links
- Smooth transitions and animations
- Neon-inspired text shadows

Responsive Layout
- Mobile-friendly design
- CSS media queries for smaller screens
- Project cards adapt from multiple columns to a single-column layout
